# Flows And Templates Index

The `memory_bank/flows/` directory contains the reusable process layer for the template: lifecycle rules, stable identifier taxonomy, and governed templates.

- [Task Workflows](workflows.md) - task routing by type, the base development cycle, and the autonomy gradient.
- [Epic Flow](epic-flow.md) - lifecycle for large initiatives with charter, roadmap, decision log, risks, subissues, and feature handoff.
- [Feature Flow](feature-flow.md) - lifecycle from a single-file `brief.md` package to conditional design / plan expansion, gates, and stable IDs (`REQ-*`, `SOL-*`, `STEP-*`).
- [Templates Index](templates/README.md) - reference templates for governed documents, including PRD, use case, epic, feature, ADR, prompt, and process docs.
