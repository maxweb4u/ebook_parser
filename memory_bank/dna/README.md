# DNA Index

DNA is the constitution of the project documentation. It defines principles, documentation rules, the frontmatter schema, and the lifecycle.

- [Principles](principles.md) — foundational project principles: SSoT, atomicity, progressive disclosure. Read this first.
- [Memory Bank Glossary](glossary.md) — definitions of governance terms such as FPF and Q-Bundle.
- [Document Governance](governance.md) — SSoT implementation and dependency tree. Answers the question: who owns each fact.
- [Frontmatter Schema](frontmatter.md) — schema for frontmatter fields.
- [Document Lifecycle](lifecycle.md) — maintenance rules and sync checklist.
- [Cross-references](cross-references.md) — rules for two-way code ↔ docs navigation.
- [Memory Bank Changelog](changelog.md) — versioned changes, migration notes, and compatibility rules for memory-bank upgrades.
- [Query Vocabulary](vocabulary.md) — Russian stems this project uses and their English equivalents, so a question asked in Russian reaches documents written in English.
