# Memory Bank Glossary

This glossary defines governance and process terms used across memory-bank documents. It does not define project domain terms; those live in [`../domain/glossary.md`](../domain/glossary.md).

## Terms

| Term | Meaning | Used for |
| --- | --- | --- |
| FPF | Fact-based First-Principles Framework. A reasoning discipline that separates facts, assumptions, reasoning, decisions, and consequences before accepting or changing a governed document. | Decision logs, review-improve loops, epic local decisions, and conflict resolution. |
| Q-Bundle | Quality Bundle. A review model where quality is evaluated through several independent dimensions instead of one scalar score. | Epic quality review, where traceability, decomposability, roadmap clarity, decision provenance, scope control, risk governance, execution handoff, evidence readiness, and change control are reviewed separately. |
